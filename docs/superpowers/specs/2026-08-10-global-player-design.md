# 전역 미리듣기 플레이어 설계 (2026-08-10)

## 목표

페이지를 이동해도 미리듣기·라디오가 끊기지 않게 한다. 단, 유저 행성에 착륙하면
그 행성의 노래(행성 라디오)로 전환되고, 은하로 나오면 듣던 곡을 이어 듣는다.

## 확정 결정 (사용자 승인)

- 행성 퇴장 시: **이전에 듣던 곡을 그 위치부터 이어듣기** (스냅샷 복원)
- 은하 밖 페이지: **하단 미니플레이어** (제목·아티스트 + 재생/일시정지/다음/정지)
- 곡 상세의 YouTube 소리 겹침: **그대로 둠** (자동 일시정지 안 함)

## 아키텍처

원본(SSOT)은 `src/player/player-context.tsx`의 `PlayerProvider` 하나다.

- 전역 오디오 객체·재생 상태(`playingId`, `isPaused`)·큐(`PlayerQueue`)·볼륨(localStorage)·
  미디어 캐시(앨범아트/미리듣기 URL, `/api/enrich` 호출 포함)를 모두 보유한다.
  루트 레이아웃에 마운트되므로 클라이언트 내비게이션 중에도 살아남는다.
- 곡이 끝나면 큐에서 미리듣기 있는 다음 곡으로 자동 진행(루프) — 기존
  GalaxyCanvas `playNextRef` 로직을 이동한 것. 캔버스가 내려가도 계속 동작한다.
- `snapshot()`/`restore()`: 행성 착륙 전 `{큐, 곡, 재생 위치}`를 저장하고 퇴장 시 복원.
- `uiHosted` 플래그: 은하 화면이 카드 패널(자체 재생 UI)을 띄우는 동안
  전역 미니플레이어를 숨긴다. 카드가 닫히면 미니플레이어가 이어받는다 —
  기존 "카드 닫으면 정지" 동작은 연결성 요구와 충돌하므로 제거.

`GalaxyCanvas`는 자체 `Audio` 객체·미디어 캐시를 버리고 이 컨텍스트만 사용한다.
`MiniPlayer`(`src/player/MiniPlayer.tsx`)는 레이아웃에 상시 렌더되고
`playingId !== null && !uiHosted`일 때만 보인다.

## 행성 착륙/퇴장 흐름

1. `landOnStar`: 착륙 시작 시 `snapshot()` 저장 (비행 중에는 은하 음악이 계속 흐른다)
2. 착륙 완료(`enterSky` → 카드 세팅) → 기존 자동 라디오(`tryRadio`)가
   행성 곡 큐로 `playFrom` — 이 순간 은하 음악이 행성 라디오로 교체된다
3. `exitSky`: 스냅샷이 있으면 `restore()`(이어듣기), 없으면 `stop()`.
   행성→행성 이동(`landByUser`)은 스냅샷을 유지한 채 건너뛴다.

## 전체 리로드 제거

오디오 생존의 전제는 클라이언트 내비게이션이다. GalaxyCanvas 안의 내부 이동
`<a href>`(곡 목록·내 취향·곡 상세 카드)를 `next/link`로 교체한다.
로그인/로그아웃(`/api/auth/*`)은 서버 리다이렉트가 필요하므로 `<a>` 유지.

## 범위 밖

YouTube 소리 겹침 처리, 은하 카메라 위치의 페이지 간 보존.
